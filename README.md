
## Project Title : Home Hero – Local Household Services
## Project Description
Home Hero is a household service marketplace where users can book local household services such as electricians, plumbers, cleaners, and more. Users can register/login, add their own services, and manage their bookings.
## Features
✅ Responsive design for all devices 
✅ Firebase Authentication (Google + Email login) ✅ Dark/Light Theme Toggle
✅ Private routes for authenticated users 
✅ Add / Manage / Delete personal services 
✅ View & cancel bookings 
✅ Dynamic “Top Rated Services” section 
✅ SweetAlert2 notifications 
✅ Modern UI with TailwindCSS + DaisyUI
##  Technologies Used
Frontend: React, React Router, React Icons Styling Tailwind CSS, DaisyUI Auth Firebase Authentication

Backend: (API) Express, MongoDB (for data fetching) Deployment Netlify (Client), Render (Server) 
## ⚙️ How to Run Locally
Clone the repository

git clone https://github.com/your-username/home-hero-client.git

Move into the project folder

cd home-hero-client

Install dependencies

npm install

Create .env.local and add your Firebase keys

VITE_apiKey=your_api_key VITE_authDomain=your_auth_domain VITE_projectId=your_project_id VITE_storageBucket=your_storage_bucket VITE_messagingSenderId=your_sender_id VITE_appId=your_app_id

Start the project

npm run dev
